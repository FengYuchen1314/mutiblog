| A02 | 后台语言全局切换 | i18n 完整度与持久化测试 | 切换后所有控制台核心页更新 |
| A03 | 永久 ID 规则 | UUID、毫秒时间戳策略、手工 slug、不可变测试 | 切换策略后仅新实体改变；验证所有语言 URL 相同且既有 URL 不变 |

## 阶段门禁

### Gate 1：基础工程

- Go 服务、Vue 控制台、渲染 CLI 都可构建；
- setup/login/health 端到端通过；
- 文件仓库能原子写入并重建 SQLite；
- CI 在干净环境通过。

### Gate 2：内容闭环

- 文章、页面、分类、标签、附件、菜单、友链可管理；
- Markdown 编辑、图片粘贴、发布、下线、回收站、修订可用；
- 默认主题生成完整源语言站点。

### Gate 3：多语言与 AI

- 数据驱动语言集合覆盖所有公开实体；
- 翻译任务可恢复；人工译文保护与回退跳转通过；
- 无 AI 配置发布路径通过。

### Gate 4：主题、评论与恢复

- 主题全生命周期；评论动态降级；备份/恢复；索引和静态输出重建全部通过。

### Gate 5：生产上线

- GitHub Actions 产生固定版本镜像；
- VPS 通过 HTTPS 提供静态站和评论 API；
- 按 A01–A27 逐项保存验证结果，失败项修复后复测。
